# 日々

依存パッケージなし（ゼロ依存）で動作する、時刻ブロック制の個人日記静的サイトジェネレータ。

---

## 特徴

- **ゼロ依存**: `node_modules` 不要。Node.js 標準機能のみで高速ビルド
- **時刻ブロック制**: 1日を分単位のファイルに分けて気負わず記録（`content/YYYY/MM/DD/HH-MM.md`）
- **Twitter ライクな投稿体験**: 日ページを開いたまま、その場で思いついたことを即座にポスト（写真添付・インライン編集対応）
- **なめらかな遷移**: View Transitions API による日付・時刻・本文のモーフィングアニメーション
- **高速なフロントエンド**: 静的 JSON によるクライアントサイド全文検索とカレンダー日付ジャンプ
- **クラウド連携**: Cloudflare R2 による写真ストレージ & Workers Static Assets への直接デプロイ

---

## 使い方

```sh
npm run dev     # 開発サーバ起動（監視・再ビルド・http://localhost:8888）
npm run new     # 今の日付・時刻のファイルを content/ に作成
npm run build   # site/ に静的サイトを出力
npm run deploy  # ビルドして Cloudflare Workers にアップロード
npm run backup  # content/ を R2 に差分バックアップ
npm run ref     # 記法デモページをブラウザで開く
```

生成物はすべて `site/` に出力され、そのまま任意の静的ホスティングへ配置できます。

## 記事の書き方

### ファイル配置

時刻ブロックごとに 1 ファイルを作成します。ディレクトリとファイル名がそのまま日付と時刻になります。

```
content/2026/08/30/10-40.md   ← 2026-08-30 10:40 の記述
content/2026/08/30/19-20.md   ← 同じ日の 19:20 の記述
```

ファイルの中身は本文のみ（時刻はファイル名 `HH-MM.md` から取得）。

### コマンドでの作成

```sh
npm run new                          # 今の時刻で空ファイルを作成
npm run new "梅雨明け。"             # 本文を指定して作成
npm run new -- -d 2026-08-29 -t 21:30 "昨日のこと。" # 日時を指定して作成
```

- `-d, --date`: `YYYY-MM-DD`
- `-t, --time`: `HH:MM`
- 同じ分のファイルがすでにある場合は、末尾に空行を挟んで追記されます。

### 記法一覧

| 記法 | 説明 |
| :--- | :--- |
| `段落` | 空行で区切る |
| `[文字](URL)` | 文中リンク（インラインコードや太字等の装飾は意図的に非対応） |
| `![キャプション](URL)` | 写真（R2 の公開 URL または日ディレクトリからの相対パス `img/x.jpg`） |
| `> 引用文`<br>`> -- 出典` | 引用（末尾に `-- 出典` を指定可能） |
| `- 項目` | 箇条書き |
| `@追記 [日付]` | 後からの追記ブロック（日付省略可） |
| `@link URL [\| タイトル \| 説明 \| サイト名 \| サムネイル]` | リンクカード（OGP をビルド時に自動取得・キャッシュ） |
| `@youtube リンク \| キャプション` | YouTube 埋め込み（共有リンク・watch・ショート・ライブ・埋め込み URL、動画 ID のどれでも可） |
| `@x ポストURL \| キャプション` | X（旧 Twitter）埋め込み（ビルド時に静的カードも生成） |
| `@map 場所 \| リンク` | 時刻ブロックの場所表示（見出しの右端に表示） |
| `@music 共有URL \| キャプション` | Apple Music 埋め込み（曲・アルバム・プレイリスト） |

記法のプレビューは `npm run ref` で確認できます。

## 執筆インターフェース

日々の記録は、確認サーバ（`npm run dev`）の日ページから **Twitter（X）のように即座につぶやく感覚でポスト** するのがメインのスタイルです。

### 日ページからのポスト投稿（メイン）

ローカルで日ページを開くと、右下に **「＋」** ボタンが表示されます。

- **即時ポスト**: 「＋」を押すとダイアログが開き、開いた時刻で現在の日時が自動セット。本文や写真を入力して投稿するだけで、該当分（`HH-MM.md`）のファイルが生成・追記されます。
- **ショートカット**: `⌘Enter`（Ctrl+Enter）で即座に投稿・保存、`Esc` で閉じます。
- **インライン編集**: 各時刻ブロックの右端にある「編集」からその場で本文を修正可能（誤字修正などに最適）。
- **モバイル対応**: スマートフォン（Tailscale 経由等）では下からせり上がるボトムシートになり、カメラや写真ライブラリから直接画像を添付できます。
- **ワンクリック同期**: 投稿・保存後に画面左下に出るトーストの「同期」を押すと、ビルドと Cloudflare へのデプロイが完了します。

> **安全設計**: この投稿・編集 UI は loopback（ローカル環境）からのアクセス時のみ動的に差し込まれるため、公開用の静的ファイル（`site/`）には一切含まれません。

### その他の執筆方法

- **コマンドライン**: `npm run new "梅雨明け。"` や `npm run new -- -d ...` でターミナルから直接作成。
- **3ペイン Web エディタ（`/_write`）**: 過去記事一覧・本文・プレビューを並べて見直せるエディタ（`http://localhost:8888/_write`）も利用可能。

詳しい内部設計やネットワーク構成は [docs/architecture.md](docs/architecture.md#執筆インターフェース) を参照してください。

## 設定と公開

### 設定（`site.config.json`）

```json
{
  "title": "日々",
  "baseUrl": "https://example.com"
}
```

※ `baseUrl` は canonical・OGP・RSS に使われるため、公開前に必ず自サイトのドメインへ変更してください。

### 環境変数（`.env`）

デプロイ・画像アップロード・バックアップに必要な設定を `.env` に記述します（`.env.example` 参照）。

```sh
# Cloudflare API（デプロイ用）
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_API_TOKEN=...

# 写真ストレージ（R2 公開バケット）
HIBI_R2_BUCKET=hibi
HIBI_R2_URL=https://img.example.com

# content/ バックアップ（R2 非公開バケット）
HIBI_R2_BACKUP_BUCKET=hibi-backup
```

### デプロイとバックアップ

```sh
# 公開（Cloudflare Workers Static Assets に差分アップロード）
npm run deploy

# content/ の R2 差分バックアップ
npm run backup

# 新しいマシンへの content/ 復元
node scripts/backup.mjs --pull
```
